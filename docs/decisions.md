## D4. Выдача кодов, срок кода, пользователь сервиса, домен портала — 2026-09-28 — действует
**Решили:** `/invite` — два шага: кому («Свой» — без лимита трафика / «Знакомый» — 200 ГБ/мес) и срок (бессрочно по умолчанию / день / неделя / месяц / полгода); заменяет «временный N дней / M ГБ» из D3. **Отбросили:** ввод произвольных дней/ГБ; поиск другого порта/домена заранее.

## D3. Тарифы инвайтов и пробный день — 2026-09-28 — действует
**Решили:** тарифы в коде: «свой» — без ограничений; «знакомый» — 200 ГБ/мес со сбросом, бессрочно; «временный» — N дней / M ГБ. После погашения на странице — пробный день 1 день / 5 ГБ на той же подписке; привязка Telegram продлевает её до тарифа. Лимит устройств не делаем.
**Почему:** сервис для своих, ограничения им не нужны; знакомым лимит трафика гасит последствия утечки ссылки. Лимит устройств в Hiddify v13 не работает, приложение Hiddify не шлёт HWID. Пробный период 1–3 дня / ~10 ГБ — норма у коммерческих ботов.
**Отбросили:** две разные подписки (пробная + постоянная) — плохой UX; ограничение по IP/устройствам.
**Подтверждено:** —
**Пересмотреть, если:** начнутся злоупотребления или жалобы хостера; люди будут забывать привязать Telegram.
