# Аудит бота — 2026-09-28

Сделан агентами (explorer/Haiku) по коду, спорные пункты перепроверены вторым проходом. Сервер не трогали.

## Что умеет

- **Пользователь:** `/start` (если в панели уже есть пользователь с его telegram_id — бот привязывает сам, `link_source='auto'`), `/status` (одна подписка: срок, трафик, ссылка), `/support` (переписка с админом, история в SQLite).
- **Новый человек:** кнопка «Запросить подключение» → заявка админу с кнопками «Одобрить / Отклонить» → при одобрении бот создаёт пользователя в панели и шлёт ссылку подписки. Заявка в БД не хранится — только сообщение админу.
- **Админ** (по `TG_ADMIN_ID`): `/broadcast` (текст/фото, 5 потоков, пауза 50 мс, только привязанные и доступные), `/bind` (мастер или `tg_id uuid`), `/sync` (подтянуть привязки из панели), `/users` (`unbound`, `blocked`), `/history <tg_id>`.
- Фоновых задач нет (ни синхронизации, ни напоминаний о сроке). HTTP-сервера нет. Long polling.

## Как работает с API Hiddify v13

- Адрес: `<HIDDIFY_BASE_URL>/<HIDDIFY_ADMIN_PROXY>/api/v2/admin/user/…`, ключ в заголовке `Hiddify-API-Key`. Таймаут 15 с, без повторов.
- Вызовы: `GET user/` (список), `GET user/<uuid>/` (статус), `POST user/` (создание), `PATCH user/<uuid>/` (telegram_id).
- Создание: имя, telegram_id, `usage_limit_GB` 100000, `package_days` 10000, `mode no_reset`, `enable`, `lang ru` (всё из env).
- Ссылка подписки: `<HIDDIFY_BASE_URL>/<HIDDIFY_USER_PROXY>/<uuid>/`.
- Порядок при одобрении правильный: сначала панель, потом SQLite; ошибка панели → админу ошибка, в БД ничего.

## apply_users (известная проблема)

- Бот Apply не вызывает, слова apply в коде нет.
- По данным vpn-ops (D15, тест 28.09): панель сама запускает `apply_users` после создания через API — сразу работает xhttp; основной профиль tcp+reality (xray) — только после следующего полного Apply. Варианты решения — `docs/design/portal.md`, раздел 5.

## Хранилище

SQLite: `users` (telegram_id ↔ hiddify_uuid, username, can_message, link_source, даты), `ticket_messages` (поддержка), `admin_sessions` (ответ админа, 30 мин). Миграции: `CREATE TABLE IF NOT EXISTS` + `ALTER TABLE` при старте.
